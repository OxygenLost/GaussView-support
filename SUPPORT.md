# GaussView Support / 帮助中心

GaussView can open `.ply`, `.splat` and `.spz` 3D Gaussian Splat models. Supported operating systems: iOS 18+ and macOS 15+.

## Importing models / 导入模型

Open **Library → Import** to choose supported files from the system file picker. You can also use another app's share sheet to open a supported model in GaussView. GaussView copies the imported file into its own library, preserving the original source file.

在模型库中点击 **Import（导入）**，通过系统文件选择器选择 PLY、SPLAT 或 SPZ 文件，也可以从其他 App 的分享菜单选择 GaussView。导入时会复制文件，不会删除或移动原文件。

## Model viewing / 查看模型

Orbit with one finger (or mouse left drag), pan with two fingers (or right drag), and pinch/scroll to zoom. Large models may take some time to load or sort on mobile devices.

单指滑动旋转、双指拖动平移、双指捏合缩放。Mac 可使用鼠标或触控板。大型模型可能需要更长的加载时间。

## iCloud / 云同步

GaussView can synchronize models using Apple's iCloud Documents when enabled and signed in. Cloud downloads may take time. If a file shows **Download now**, tap it and wait. When iCloud is unavailable, locally stored files remain available.

启用并登录 Apple iCloud 云盘后，可使用模型同步功能。云端文件需要下载，若出现 **Download now**，点击后等待即可。iCloud 不可用时，本地已存模型仍可访问。

## GaussView Pro / 永久版

GaussView Pro is an optional one-time in-app purchase; there is no subscription. It unlocks professional tools such as PNG export and the model inspector. Model viewing and the existing model library remain free. Open **GaussView Pro → Restore Purchases** to restore entitlements on supported devices using the same Apple Account. If a product or price is not available, check connectivity and retry. Refunds and revoked purchases may remove Pro access.

GaussView Pro 为可选的一次性永久购买，不是订阅。解锁 PNG 图片导出、模型信息等专业功能；免费版仍可查看模型、使用原有模型库。在同一个 Apple 账户的设备上，可进入 **GaussView Pro → Restore Purchases（恢复购买）**。若价格暂时不可用，请检查网络后重试。退款或撤销交易可能导致 Pro 权益失效。

## Contact / 反馈问题

[Open a support issue / 提交反馈](https://github.com/OxygenLost/GaussView-support/issues/new)

Please include your device type, OS version and steps to reproduce the issue. GitHub issues are **public**: do not share passwords, payment details, private documents or models unless you are comfortable publishing them.

反馈时建议说明设备型号、系统版本及复现步骤。GitHub Issue 是**公开内容**，请勿上传密码、支付信息或私人模型文件。
