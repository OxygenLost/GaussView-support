# GaussView Support / 帮助中心

GaussView is a 3D Gaussian Splat viewer for iPhone, iPad and Mac. It supports `.ply`, `.splat`, and `.spz` files.

**Public resources**
- [Privacy Policy / 隐私政策](PRIVACY.md)
- [Support and FAQ / 使用帮助](SUPPORT.md)
- [Report a problem / 反馈问题](https://github.com/OxygenLost/GaussView-support/issues/new)

Please note: GitHub issues are public. Never post Apple Account passwords, billing details, or private model files.

This repository hosts customer-facing legal and support documents. It does not contain the GaussView app source, user models or payment information.
